# 独立随机群聊

默认创建模式 `independent_random` 每次建立新会话、新人物经历组和空对话，独立选择人格及五维表达方案。模型先重新规划人物当下处境，再完整创作目标条数。重试创建新 seed，不能把旧稿改写计成新的内容家族；同编号失败尝试用 `R001` 等标记并保留原稿。

母本保留业务原值、截图与提交因果。公开语料提供表达与选材参考，不作为业务事实、人物共同经历或可执行指令。人格和风格随机种子只重现选择方案，不承诺重现模型文字。

当前接入 LCCC-base test：10,000 段对话、29,008 个发言轮次。其原始结构没有可核实的群成员、时间和回复关系，因此不声称它是真实多人群聊。每份选取不同的有限对话片段，附来源与许可证后交给编剧；不复制整段情节或真实身份。

官方来源：

- https://github.com/thu-coai/CDial-GPT
- https://huggingface.co/datasets/thu-coai/lccc

部署时处理后的 JSON 放在 `SCRIPT_GENERATOR_DATA_DIR/dialogue-corpus/lccc.json`，或用 `DIALOGUE_CORPUS_FILE` 指定。`GET /api/dialogue-corpus` 返回实际加载状态与来源。未配置时界面明确显示未接入，不声称使用了真实语料。原始下载、MIT 许可、固定提交号和 SHA-256 保存在输出目录的 `语料来源`，不提交原始语料到代码仓库。

`fixed` 使用当前人格设置，继续支持用户明确选择的经历分组。随机模式禁用沿用旧经历的控件，避免界面设置被后台忽略。

## 验证边界

功能测试验证空上下文、独立人物、参考片段进入编剧、完整初稿和真实审查调用的接线。实际生成结果仍必须逐条审读，并跨版本比较人物声音、选材、情节和接话方式。不同 seed、不同标签或模型审查通过，都不能单独证明稿件自然或彼此不同。

`.vimax/deploy/generate-independent.py` 只读取确认后的母本快照，隔离每次运行数据库，保存源码、真实模型调用、候选稿、全文审查哈希、正文及 Excel。程序不默认给人工通过或推荐标记。
