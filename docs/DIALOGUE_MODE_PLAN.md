# ViMax 群聊剧本模式

目标：上传九列 Excel 母本，以坐席内容确定对话目的、必要说明和操作因果关系，生成自然的指定条数群聊，并导出同格式 Excel / JSON。母本原账号只作来源记录，不要求沿用或逐人出场；参与者数量、人格和语言可重新设置。

实现：直接在 ViMax 原工作台新增群聊模式，共用原导航、项目列表和生成文件视图，工作台改为中文。`dialogue/` 只承载后台功能，复用用户现有应用的母本解析、目标确认、角色卡、独立人物记忆、事实保护、恢复与导出。ViMax `Screenwriter` 增加可选创作提示词入口，原影视行为保留默认值，群聊模式使用专门的事件规划和写作提示词。

数据：新模式默认写入 `.vimax/dialogue/`，不读取或修改旧数据库。密钥只从进程环境或指定 DPAPI 文件加载。母本、生成结果、日志和密钥不提交到 Git。

验收：真实母本导入，沿用已确认的坐席内容目的，参与者可重新设置，不强制原账号出场。第二轮使用10位可选参与者，生成150条完整消息。检查首尾坐席、回复关系、原值、业务顺序、目标完成、重复与人物前后矛盾；核对导出的九列表头与150条内容。程序审阅、人工通读和接口完成分别记录。

当前授权限于本地开发和真实母本试跑。创建独立分支和 PR，未部署服务器。
